# JEV 判定链（实验性）

**默认不要用。** 这条链是实验性质，只在明确要求"按视觉判定网页状态"时才启用。

## 前提

- 必须配了 JEV 或 Laya 的 Key，否则这 5 个工具不注入；即使注入，调用也只会回"未配置"；
- 五个工具是一套流水：`bcdp_jev_status` → `bcdp_jev_ask` / `bcdp_jev_frame` → `bcdp_jev_run` → `bcdp_jev_attempt`。

## 什么时候值得用

- 需要用"看图判断"来确认状态（不是读 DOM 文本能得出的结论）；
- 需要一次判定产出可复用的证据（帧 + 结论 + 尝试记录）。

## 什么时候不要用

- 只是想确认"页面变了没" → 用 `bcdp_snapshot` / `bcdp_page_info`；
- 只是想截个图给人看 → 用 `bcdp_screenshot`；
- 没配 Key → 直接跳过，不要反复试探。

## 失败处理

判定链失败时**不要自动重试整条链**：先 `bcdp_jev_status` 看链路可用性，确认是"未配置"还是"判定无结论"。判定无结论时把事实（帧、目标、失败原因）回给用户，不要替用户下结论。
